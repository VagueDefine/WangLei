## 一、电阻的主要参数

### 1.1 标称阻值与精度
- 常用精度等级：$1\%$（`E96`系列）、$5\%$（`E24`系列）
- 高速电路中对匹配精度要求高的场景（如差分端接）应选 $1\%$ 精度
- 精密电阻（$0.1\%$、$0.01\%$）用于反馈分压、电流检测等
**当电阻用于设定器件的工作参数时，应选择高精度电阻**

### 1.2 额定功率
- 常用封装与额定功率对照：

| 常见封装       | 额定功率  |
| ---------- | ----- |
| 0201       | 1/20W |
| 0402       | 1/16W |
| 0603（1608） | 1/10W |
| 0805（2012） | 1/8W  |
| 1206（3216） | 1/4W  
`以上尺寸均为EIA代码，单位为in,（1in=100mil），例如0603代表，长度0.6in=60mil，宽度为0.3in=30mil；也有公制代码，0603及对应1608，表示长1.6mm，宽0.8mm。

- **选型铁律**：实际功耗应不超过额定功率的 $80\%$，需留余量
- 案例一中的 0402 电阻因功率不足导致爆裂，需按最大工作电流核算

### 1.3 耐压值
- 小封装电阻耐压较低（如 0402 耐压约 50V）
- 高压应用（如电源电路）需注意耐压是否满足

## 二、高频特性

### 2.1 寄生参数
- 电阻在高频时呈现 $RLC$ 串联模型：
  - 寄生电感：约 $0.5~2nH$（贴片电阻，与封装相关）
  - 寄生电容：约 $0.1~0.5pF$
- 自谐振频率 $SRF$：超过此频率后电阻呈感性或容性

### 2.2 频率响应
- 薄膜电阻的频率特性优于厚膜电阻
- 小封装电阻的寄生参数更小，高频性能更好
- 对于 $1GHz$ 以上的信号，需考虑电阻的 S 参数模型

## 三、典型应用场景

### 3.1 上拉与下拉电阻
- **目的**：确定默认电平、提供驱动电流
- **阻值选择**：
  - 过小：功耗大、驱动电流过大
  - 过大：上升沿变缓（$RC$ 时间常数增大）
  - 经验值：`I2C` 总线上拉 $4.7kΩ~10kΩ$；通用逻辑信号上拉 $10kΩ$
- **案例**：案例一中的告警信号因串联电阻过大（$1kΩ$）导致分压后电平超出逻辑门限

### 3.2 串联终端匹配电阻
- **目的**：抑制信号反射、减缓过冲/振铃
- **阻值**：等于传输线特性阻抗减去驱动源输出阻抗，通常 $22Ω \sim 33Ω$
- **布放**：必须靠近驱动端放置
- 串联电阻的加入会形成分压，需考虑对逻辑电平的影响

### 3.3 下拉电阻与总线保持
- 在总线空闲时维持确定电平，防止浮动输入导致逻辑混乱
- 多驱动源总线（如 `PCI`、`Local Bus`）每条信号线需加弱下拉

### 3.4 分压电阻
- 用于电平转换、电压检测、`ADC` 采样等
- **选型注意**：
  - 总阻值过大→采样电流过小→易受噪声干扰
  - 总阻值过小→功耗过大
  - 一般控制支路电流在 $0.1~1mA$ 范围

### 3.5 零欧姆电阻（跳线电阻）
- 实际阻值并非 $0Ω$，通常为 $10 \sim 50mΩ$
- 用途：单板配置选择、调试断点、模拟/数字地分割桥接
- 额定电流需按实际载流核算

### 3.6 电流检测电阻
- 要求低温漂、低感抗
- 常用 `Kelvin` 连接（四线开尔文）消除引线电阻影响
- 封装需考虑散热

## 四、PCB 布局要点

| 要点    | 说明                  |
| ----- | ------------------- |
| 靠近放置  | 串联匹配电阻必须紧靠驱动器件引脚    |
| 远离干扰源 | 高阻值电阻易耦合噪声，远离开关节点   |
| 散热考虑  | 功率电阻周围留散热空间，远离热敏感器件 |
| 地平面完整 | 电阻下方尽量保持完整地平面       |

## 五、选型 checklist

- [ ] 阻值和精度是否满足电路要求？
- [ ] 额定功率是否留有 80% 以上余量？
- [ ] 封装尺寸是否满足 PCB 空间和散热要求？
- [ ] 频率是否在电阻的自谐振频率以下？
- [ ] 耐压值是否满足应用需求？
- [ ] 温度系数（TCR）是否满足精度要求？
- [ ] 是否考虑了电阻的寄生参数影响？
