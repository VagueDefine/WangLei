## 一、磁珠的工作原理

磁珠（Ferrite Bead）是铁氧体材料制成的单匝或多匝电感器件。与电感的核心区别：

| 特性 | 磁珠 | 电感 |
|------|------|------|
| 损耗模式 | 电阻性（将噪声转换为热） | 电抗性（反射噪声） |
| 频率特性 | 宽频带高阻抗 | 窄频带谐振 |
| 直流特性 | DC 偏置会降低阻抗 | DC 偏置会降低感量 |
| 应用目的 | 吸收高频噪声 | 储能、滤波 |

**核心特点**：磁珠在低频段呈感性，在某一频率后转为电阻性（阻抗曲线交叉点）

## 二、主要参数

### 2.1 阻抗 $Z$ @ 100MHz
- 最关键的选型参数，通常标注 "600Ω@100MHz"
- 表示在 100MHz 时磁珠的阻抗模值
- 实际阻抗 = $\sqrt{R^2 + X_L^2}$，其中 R 是损耗电阻，$X_L$ 是感抗

### 2.2 直流电阻 DCR
- 小电流（<100mA）场景 DCR 通常 <0.1Ω
- 大电流（>500mA）场景需关注 DCR 引起的压降和发热
- 一般不要用磁珠走大电流，优先用电感

### 2.3 额定电流 $I_{rated}$
- 超过额定电流时磁珠饱和，阻抗急剧下降
- **选型铁律**：实际工作电流 ≤ 70% × $I_{rated}$
- 磁珠的磁芯在 DC 偏置下磁导率下降，阻抗曲线偏移

### 2.4 频率特性曲线
- 选型必须参考规格书中的 Z/R/X 曲线
- 交叉频率（R = $X_L$ 的频率）需覆盖目标噪声频段
- SRF 以上的高频段呈容性，需注意

## 三、典型应用场景

### 3.1 电源去耦隔离
- 模拟电源与数字电源之间的隔离
- 时钟、PLL、ADC/DAC 等敏感器件的电源
- RF 电路的电源去耦
- **注意**：磁珠只隔离高频噪声，对 DC 和低频是直通

### 3.2 信号线 EMI 抑制
- 高频信号线（时钟、数据线、SerDes）串联磁珠
- **禁止用在**：I2C、SPI、UART 等低速总线
- 通用规则：信号频率 > 10MHz 可用磁珠

### 3.3 I/O 接口滤波
- 电源输入口串联磁珠抑制传导发射
- 在接口连接器附近放置

## 四、磁珠 vs 电感

| 比较项 | 磁珠 | 电感 |
|--------|------|------|
| DCR | 较小（通常 <0.5Ω） | 可大（如 0.3Ω） |
| 额定电流 | 中小（通常 <1A） | 可大（>10A） |
| 高频特性 | 宽频高阻抗 | 单频谐振 |
| 工作机理 | 吸收损耗 | 储能反射 |
| 适用频段 | 10MHz~1GHz | <100MHz |
| SRF | 通常 200~500MHz | 几十 MHz~几百 MHz |
| 互替性 | 不可用电感替换 | 在合适频段可替代 |

## 五、正确使用姿势

### 5.1 磁珠 + 电容形成 π 型滤波
- 推荐拓扑：磁珠在中间，两边各一颗对地电容
- 输入电容 → 磁珠 → 输出电容
- 电源入口 ± 磁珠两侧都需加电容

### 5.2 避免谐振
- 磁珠呈感性时与电容形成 LC 谐振
- 可在磁珠两端并联阻尼电阻（10~100Ω）
- 选用损耗占主导的磁珠（R >> $X_L$）

### 5.3 PCB 布局要求
- 磁珠靠近噪声源侧放置
- 滤波电容尽量靠近磁珠两侧
- 保证磁珠下方无地平面开槽

## 六、选型 checklist

- [ ] 100MHz 阻抗是否满足目标噪声抑制需求？
- [ ] DCR 引起的压降是否在可接受范围？
- [ ] 额定电流 ≥ 2 倍最大工作电流？
- [ ] 频率特性曲线是否覆盖目标噪声频段？
- [ ] 是否确保磁珠工作在电阻主导频段？
- [ ] 磁珠 + 电容组合是否存在谐振风险？
- [ ] 在信号线上使用时是否考虑了对信号质量的影响？
