## 一、概述

高速逻辑电平主要用于 100Mbps~10Gbps+ 的串行数据传输。三种主流电平对比：

| 参数 | LVDS | LVPECL | CML |
|------|------|--------|-----|
| 输出摆幅 | ±350mV | ±600~800mV | ±400mV |
| 共模电压 | 1.2V | $V_{CC} - 1.3V$ | $V_{CC} - 0.2V$ |
| 供电 | 3.3V/2.5V/1.8V | 3.3V/2.5V | 3.3V/1.8V |
| 功耗 | 低（~3mW） | 高（~60mW） | 中（~30mW） |
| 速率 | DC~3.125Gbps | DC~10Gbps+ | DC~10Gbps+ |
| 驱动方式 | 电流源（3.5mA） | 射随器 | 集电极开路 |
| 端接 | 100Ω 差分 | 戴维南或 $V_{CC}-2V$ | 50Ω 到 VCC |

## 二、LVDS（低压差分信号）

### 2.1 工作原理
- 3.5mA 恒流源驱动，通过 100Ω 端接电阻产生 ±350mV 差分电压
- 低摆幅 → 高速、低功耗、低 EMI

### 2.2 端接要求
- 在接收端差分对之间跨接 **100Ω ±1%** 电阻
- 端接电阻必须紧靠接收器引脚

### 2.3 PCB 设计要点
- 差分对阻抗控制在 100Ω ±10%
- 差分对内等长（±5mil）
- 差分对间距 ≥ 3 倍线宽（3W 原则）
- 远离其他信号线 ≥ 3H
- 尽量避免换层，如需换层则在换层处加地过孔

### 2.4 应用场景
- 高速数据总线（Gigabit Ethernet、SATA、PCIe）
- 时钟分配
- 视频接口（LVDS 显示屏）

## 三、LVPECL（低压正射极耦合逻辑）

### 3.1 工作原理
- 差分射极跟随器输出结构
- 输出摆幅 600~800mV
- 输出共模 $V_{CC} - 1.3V$（3.3V 时约 2.0V）

### 3.2 端接方式

**方式一：戴维南等效**
- $R_1$（到 VCC）= 130Ω
- $R_2$（到 GND）= 82Ω
- 等效于 50Ω 拉到 $V_{CC} - 2V$

**方式二：Y 型端接**
- 直接使用 50Ω 到 $V_{TT} = V_{CC} - 2V$
- 需额外产生 $V_{TT}$ 电源，不常用

### 3.3 注意事项
- LVPECL 功耗较大，需考虑散热
- 输出端不可直接对地短路
- AC 耦合后需在接收端提供偏置

## 四、CML（电流模式逻辑）

### 4.1 工作原理
- 集电极开路差分输出
- 输出摆幅由负载电阻 $R_{load}$ 和偏置电流决定
- 典型 $R_{load}=50\Omega$，摆幅约 400mV

### 4.2 端接
- 输出端上拉到 VCC 的 50Ω 电阻
- 或 AC 耦合后接收端 50Ω 到偏置电压

### 4.3 应用场景
- 高速 SerDes（PCIe、SATA、XFI）
- >1Gbps 的串行通信

## 五、电平互连指南

| 发送 | 接收 | 连接方式 |
|------|------|---------|
| LVDS | LVDS | 直接连接，100Ω 端接 |
| LVPECL | LVDS | AC 耦合 + 衰减网络（3:1 分压） |
| LVDS | LVPECL | AC 耦合 + 偏置网络 |
| LVPECL | CML | AC 耦合 + 偏置 |
| CML | LVPECL | AC 耦合 + 偏置 |
| CML | CML | 直接连接（相同供电时）或 AC 耦合 |

**基本原则**：
- 直接连接：共模电压和摆幅兼容时
- AC 耦合：共模不兼容时必须用
- 无 DC 路径时需提供偏置电压

## 六、PCB 设计通用要点

- 差分阻抗控制（100Ω LVDS，50Ω 单端 LVPECL/CML）
- 差分对内等长（±5mil 以内）
- 同一差分对走线间距恒定
- 差分对间间距 ≥ 3W
- 地平面开槽避免跨分割
- 交流耦合电容（0.01~0.1μF）靠近接收端放置

## 七、选型 checklist

- [ ] 传输速率是否在所选电平的范围内？
- [ ] 供电电压是否与电平兼容？
- [ ] 输出摆幅是否满足接收器要求？
- [ ] 共模电压是否匹配（直接连接时）？
- [ ] 端接方式是否正确？
- [ ] PCB 差分阻抗是否可控？
- [ ] 功耗是否在可接受范围？
- [ ] 是否需要 AC 耦合？
