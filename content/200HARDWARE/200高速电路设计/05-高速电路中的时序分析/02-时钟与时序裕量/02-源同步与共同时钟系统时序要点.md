## 一、源同步系统（Source Synchronous）

### 1.1 原理
- 数据和随路时钟一起发送
- 接收端用随路时钟采样数据
- 时钟和数据的相对时序由 PCB 走线差决定

### 1.2 时序公式
$$t_{VB} = T_{clk} - (t_{CO(max)} + t_{skew} + t_{jitter})$$
$$t_{SU(margin)} = t_{VB} - t_{SU(rcv)}$$
$$t_{H(margin)} = t_{CO(min)} - t_{skew} - t_{H(rcv)}$$

### 1.3 应用
- DDR/DDR2/DDR3/DDR4 接口
- SerDes（内嵌时钟）
- SPI（带随路时钟）

## 二、共同时钟系统（Common Clock）

### 2.1 原理
- 发送端和接收端使用同一个时钟源
- 时钟通过分配网络到达两端
- 时序受时钟偏斜影响较大

### 2.2 时序公式
$$t_{SU(margin)} = T_{clk} - (t_{CO(max)} + t_{PD(max)} + t_{SU(rcv)} + t_{skew})$$
$$t_{H(margin)} = (t_{CO(min)} + t_{PD(min)}) - (t_{H(rcv)} + t_{skew})$$

### 2.3 应用
- 传统同步总线
- 较低速接口（< 200MHz）

## 三、两种系统比较

| 特性 | 源同步 | 共同时钟 |
|------|--------|---------|
| 时钟源 | 随路 | 共用 |
| 最高频率 | ~GHz | ~200MHz |
| 走线要求 | 数据和时钟等长 | 时钟偏斜控制 |
| PCB 复杂度 | 中等 | 较低 |
| 主频限制因素 | 走线差 | 时钟偏斜 |

## 四、设计要点

### 4.1 源同步
- 数据和随路时钟必须等长
- 使用 length tuning（蛇形线）补偿
- 接收端 PLL/DLL 用于相位调整

### 4.2 共同时钟
- 时钟分配网络必须平衡
- 时钟偏斜控制在允许范围内
- 常用于低速接口

## 五、设计 checklist

- [ ] 确定使用源同步还是共同时钟？
- [ ] 源同步：数据和时钟等长（±50mil）？
- [ ] 共同时钟：时钟偏斜在允许范围？
- [ ] 时序裕量全温度范围验证？
- [ ] 接收端的采样窗口满足要求？
