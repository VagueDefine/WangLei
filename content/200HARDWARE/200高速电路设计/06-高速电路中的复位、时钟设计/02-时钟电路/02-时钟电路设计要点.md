## 一、晶体与晶振

### 1.1 晶体（Crystal） vs 晶振（Oscillator）

| 对比项 | 晶体 | 晶振 |
|--------|------|------|
| 内部结构 | 仅石英片 | 晶体+振荡电路 |
| 是否需要外部电路 | 需要 | 不需要 |
| 输出信号 | 正弦波 | 方波/削峰正弦波 |
| 频率精度 | ±25~±100ppm | ±10~±50ppm |
| 成本 | 低 | 高 |

### 1.2 晶体选型参数
- 标称频率
- 负载电容 $C_L$
- ESR（等效串联电阻）
- 频率精度和温度稳定性
- 激励功率

### 1.3 PCB 布局要点
- 晶体和负载电容紧靠 IC 的 OSC 引脚
- 走线尽量短（< 500mil）
- 晶体下方不走其他信号线
- 晶体外壳接地

## 二、锁相环（PLL）

### 2.1 PLL 组成
- 鉴相器（PFD）
- 环路滤波器（LF）
- 压控振荡器（VCO）
- 分频器（Divider）

### 2.2 环路滤波器
- 决定 PLL 带宽
- 带宽越窄 → 对 VCO 噪声抑制越好
- 带宽越宽 → 对参考时钟跟踪越快
- **关键时钟使用外部环路滤波器**

### 2.3 PLL 级联原则
- 避免级联
- 必须级联时：第二级带宽 > 第一级带宽
- 使用专用时钟发生器替代多级 PLL

## 三、时钟抖动

### 3.1 抖动分类
- 随机抖动（RJ）：高斯分布，热噪声引起
- 确定性抖动（DJ）：有界，电源噪声/串扰/ISI 引起

### 3.2 抖动来源
| 来源 | 典型抖动 | 频段 |
|------|---------|------|
| 晶体振荡器 | 0.5~5ps RMS | 低频 |
| PLL | 1~20ps RMS | 中频 |
| 电源噪声 | 1~10ps | 宽带 |
| 串扰 | 10~100ps | 高频 |

### 3.3 时钟抖动对系统的影响
- ADC：降低 SNR
- SerDes：增加误码率
- 时序：消耗建立/保持时间裕量

## 四、时钟分配

- 使用低 skew 时钟缓冲器
- 各分支走线等长
- 时钟线离其他信号 ≥ 3W
- 时钟走线加地屏蔽
- 关键时钟走内层（带状线）

## 五、设计 checklist

- [ ] 晶体频率精度满足系统要求（±25ppm/±50ppm）？
- [ ] 晶体 ESR 和负载电容匹配？
- [ ] PLL 环路滤波器设计正确？
- [ ] PLL 级联避免或已确认抖动预算？
- [ ] 时钟抖动满足 SerDes/ADC 要求？
- [ ] 时钟走线远离其他信号（≥ 3W）？
- [ ] 时钟缓冲器 fanout 不超规格？
- [ ] 时钟源供电有 LC 滤波？
