## 一、反射

### 1.1 反射系数
$$\Gamma = \frac{Z_L - Z_0}{Z_L + Z_0}$$
- $\Gamma = 0$：完美匹配
- $\Gamma = 1$：开路
- $\Gamma = -1$：短路

### 1.2 端接类型

| 类型 | 适用 | 优点 | 缺点 |
|------|------|------|------|
| 源端串联 | 点对点 | 低功耗 | 不适合多负载 |
| 末端并联 | 点对多点 | 吸收好 | 功耗大 |
| 戴维南 | 需要偏置 | 端接+偏置 | 功耗大 |
| RC AC | 低功耗 | 无 DC 功耗 | 低频失真 |
| 差分 | 差分信号 | 标准要求 | - |

## 二、串扰

### 2.1 3W 原则
间距 ≥ 3 倍线宽，串扰降低到 5% 以下。

### 2.2 串扰控制
- 相邻层走线垂直
- 关键信号加地屏蔽
- 高速信号走内层

## 三、端接选择

| 场景 | 推荐 |
|------|------|
| 点对点时钟 | 源端串联 |
| 点对多点总线 | 末端并联 |
| LVDS | 100Ω 差分 |
| 低功耗 | AC 端接 |
| DDR 数据 | ODT |

## 四、设计 checklist

- [ ] 端接方案与拓扑匹配？
- [ ] 串扰间距 ≥ 3W？
- [ ] 相邻层走线垂直？
- [ ] 过冲 < 20%？
- [ ] 振铃 2 周期内衰减？
