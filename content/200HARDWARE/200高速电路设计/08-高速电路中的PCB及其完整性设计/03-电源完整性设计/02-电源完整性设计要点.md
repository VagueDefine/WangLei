## 一、PDN 阻抗组成

| 频段 | 决定因素 |
|------|---------|
| DC~1kHz | VRM |
| 1kHz~1MHz | VRM 环路 |
| 1MHz~100MHz | 板级去耦 |
| 100MHz~1GHz | 电源/地平面 |
| > 1GHz | 封装/片上 |

## 二、电容特性

### 2.1 封装 ESL

| 封装 | ESL (nH) |
|------|---------|
| 1206 | ~1.5 |
| 0805 | ~1.0 |
| 0603 | ~0.7 |
| 0402 | ~0.5 |
| 0201 | ~0.3 |

### 2.2 布局要点
- 高频电容 < 30mil 到引脚
- 独立过孔
- 容值多样覆盖全频段
- 反谐振点低于目标阻抗

## 三、平面电容
- 间距 < 4mil 提供高频去耦
- 介质越薄、电容越大

## 四、DC IR Drop
- 使用电源平面
- 增加铜厚
- 远端采样补偿

## 五、设计 checklist

- [ ] PDN 目标阻抗计算？
- [ ] 电容覆盖全频段？
- [ ] 反谐振抑制？
- [ ] 平面电容利用？
- [ ] IR Drop < 3%？
