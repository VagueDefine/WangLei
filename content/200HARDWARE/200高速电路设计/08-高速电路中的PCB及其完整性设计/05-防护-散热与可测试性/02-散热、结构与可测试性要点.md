## 一、散热设计

### 1.1 热源识别
- 大功率 IC（CPU、FPGA、SerDes）
- 电源器件（MOSFET、电感、LDO）
- 高电流走线

### 1.2 散热方法

| 方法 | 适用 |
|------|------|
| 铜皮散热 | 中等功耗 |
| 散热过孔 | 热源到底层铜皮 |
| 散热器 | 大功率器件 |
| 风冷 | 系统级 |
| 导热垫/导热胶 | IC 到外壳 |

### 1.3 PCB 散热要点
- 热源下方加散热过孔阵列
- 电源器件多铜皮
- 大电流走线加宽加铜厚
- 发热器件远离热敏感器件

## 二、结构易用性

### 2.1 连接器布局
- 连接器排列顺序符合用户习惯
- 同类型接口集中布置
- 插拔方向一致
- 指示灯与对应接口位置对应

### 2.2 板卡尺寸
- 符合标准规格（PCIe、ATCA等）
- 安装孔位置合理
- 器件高度不冲突

## 三、可测试性

### 3.1 测试点
- 关键电源轨预留测试点
- 高速信号预留 SMA 或测试焊盘
- JTAG/SWD 调试接口
- 测试点间距满足探针要求

### 3.2 调试辅助
- LED 指示灯（电源、状态）
- 拨码开关
- 串口调试接口
- 复位按钮

## 四、设计 checklist

- [ ] 散热方案满足热预算？
- [ ] 散热过孔阵列充足？
- [ ] 发热器件远离热敏感器件？
- [ ] 连接器布局合理？
- [ ] 测试点覆盖关键信号？
- [ ] JTAG/SWD 接口引出？
- [ ] 调试 LED 和串口？
