18、运放稳定性三步判据笔记

18、运放稳定性三步判据笔记

Apr 27, 20265 min read

运算放大器稳定性快速判断笔记（工程实用版）

目标：看到任何一个运放电路，在 1–2 分钟内判断是否稳定，不依赖复杂推导。

一、核心思想（先建立正确直觉）

  • 稳定性 ≠ 拓扑是否有负反馈
  • 稳定性本质是：

噪声增益曲线 与 运放开环增益曲线 的交点斜率

只要在交越频率处形成 −40 dB/dec 等效斜率 → 相位裕度不足 → 振荡。

二、三步快速判断法（通用于同相 / 反相 / 跟随 / TIA）

第 1 步：先看运放本身（不看外围）

1️⃣ 必查的三条参数

  • 是否 Unity-gain stable（单位增益稳定）
  • 是否标注 Minimum Stable Gain
  • 允许的 容性负载范围

2️⃣ 快速分级

运放类型稳定性风险
单位增益稳定低
最小稳定增益 ≥ 2中
未补偿 / 高速运放高

📌 结论：

非单位增益稳定的运放，跟随器必不稳

第 2 步：站在运放引脚“向外看”

2.1 看输入端（源阻抗）

判断输入端看到的是否是 RC 网络：

  • 低阻源（<100 Ω） → 安全
  • 分压器 / 传感器 / 大电阻 → 风险

经验判据：

2.2 看输出端（负载）

输出负载风险
纯电阻安全
< 5 pF可接受
> 10 pF高风险
电缆 / ADC / 滤波电容极高风险

📌 工程铁律：

单位增益 + 电容负载 = 高频振荡高发区

第 3 步：判断噪声增益形状（不用画完整 Bode）

3.1 低频噪声增益是多少？

拓扑低频噪声增益
跟随器1
同相(1+R_f/R_g)
反相≥ 1
TIA≥ 1

👉 低频噪声增益越低，稳定性越差

3.2 是否存在“噪声增益上升因素”？

只要看到以下任意一条，就要警惕：

  • 输入端 RC（分压 + 电容）
  • 反相端输入电容
  • 反馈电阻很大
  • 高阻节点连接运放输入

👉 这些都会导致：

噪声增益 +20 dB/dec 上升

3.3 斜率交越快速判据

交越斜率判断
−20 dB/dec稳定
−40 dB/dec临界
< −40 dB/dec振荡

📌 核心结论：

噪声增益 +20 dB/dec 与 运放 −20 dB/dec 相交 → 等效 −40 → 不稳

三、不同拓扑的稳定性关注点

1️⃣ 同相放大器

  • 稳定性由 噪声增益 = 1 + Rf/Rg 决定
  • 输入端分压 + 输入电容会引入零点
  • 常见问题：
    • 跟随器（NG=1）最危险

2️⃣ 反相放大器

  • 输入阻抗 ≈ Rin
  • 高频时输入电容会抬高噪声增益
  • 常见补偿：
    • 反馈电阻并联 Cf

3️⃣ TIA（跨阻放大器）

  • 噪声增益由 Cf 与 Cin 决定
  • 关键设计目标：
    • 让噪声增益在交越前变平

临界补偿经验形式：

极点 fp 与运放 GBW 对齐 → 临界稳定

四、工程保命三板斧（不想算时）

1️⃣ 输出串联 10–51 Ω

2️⃣ 反馈电阻并 1–10 pF

3️⃣ 整体电阻值缩小 5–10 倍

👉 90% 情况可直接稳定

五、一句话总总结

运放稳不稳， 不看是不是负反馈， 只看噪声增益怎么走。

（本笔记适用于工程设计、论文分析与快速电路评估）
