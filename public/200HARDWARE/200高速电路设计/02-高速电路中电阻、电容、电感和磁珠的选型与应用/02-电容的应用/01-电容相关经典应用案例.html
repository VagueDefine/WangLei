一、相关案例

案例一：去耦电容布放不当导致逻辑芯片工作异常

某产品 CPU 核心电压 1.2V 采用多颗 0.1μF 陶瓷去耦电容，功能测试发现 CPU 在高频运行时偶发死机。测量核心电压纹波高达 150mV，远超 CPU 要求的 ±5%（60mV）范围。

讨论

检查 PCB 布局发现，去耦电容与 CPU 电源引脚之间的过孔和走线过长，导致回路电感过大。去耦电容的等效串联电感（ESL）加上 PCB 走线电感，使得电容在 CPU 高频瞬态电流需求时无法及时响应。

等效分析：去耦回路的电感 L 与电容 C 形成 LC 谐振，谐振频率 。当回路电感过大时，谐振频率降低，导致在 CPU 工作频率附近失去去耦效果。

改进：将去耦电容紧靠 CPU 电源引脚放置，走线宽度加粗，过孔从 0.3mm 加大到 0.5mm，并增加过孔数量。改进后纹波降至 35mV。

案例二：MLCC 电容 DC 偏压特性导致电源纹波超标

某 3.3V 电源输出采用 10μF/10V X5R 陶瓷电容滤波，实测纹波达 80mV，超出设计指标 50mV。

讨论

查阅 MLCC 电容规格书发现，10μF X5R 电容在施加 3.3V DC 偏压时，实际容值仅为标称值的 30%（约 3μF）。X5R/X7R 类陶瓷电容的介电常数随 DC 偏压增加而显著下降。

改进：将电容更换为同容值的 X7R 材质（电偏压特性略好），或将额定电压选为 6.3V 以降低偏压影响比，最终采用 22μF/6.3V 电容，在 3.3V 偏压下仍有约 12μF 有效容值，纹波降至 25mV。

启示：选陶瓷电容时必须参考规格书中的 DC 偏压特性曲线，不可仅凭标称容值选型。

案例三：电容 ESL 过大导致高频滤波失效

某 SerDes 高速收发器 1.0V 电源采用 10μF 电容加多个 0.1μF 电容滤波。在 1GHz 频段测得的电源噪声达到 40mVpp，超出 SerDes 对电源噪声的要求。

讨论

分析发现，0.1μF 电容（0603 封装）的自谐振频率约 40MHz，在 1GHz 时已经呈感性，丧失滤波能力。SerDes 对 1GHz 附近噪声敏感。

改进：在 0.1μF 电容基础上，并联 100pF（0402 封装）和 10pF（0201 封装）电容，利用小封装电容的低 ESL 特性将去耦频率推到 GHz 级别。改进后 1GHz 噪声降至 8mVpp。

案例四：电容 ESR 过小引发 LLC 谐振电源振荡

某 LLC 谐振变换器的谐振电容采用低 ESR 的 C0G 材质电容，调试时发现在轻载条件下输出不稳定，频率抖动的现象。

讨论

LLC 电路中的谐振电容 ESR 提供阻尼，过低的 ESR 导致谐振回路 Q 值过高，在轻载时环路不稳定。电容的 ESR 是 LLC 设计中的一个关键参数。

改进：在谐振电容上串联一个小电阻增加阻尼，或将部分 C0G 电容更换为 ESR 略大的 X7R 电容。

案例五：电容温度特性造成的产品低温失效

某通讯设备在低温实验（-40°C）时，电源输出电压偏低，导致系统频繁复位。

讨论

检查发现输出滤波电容使用了 Y5V 材质电容。Y5V 在 -40°C 时容值下降至标称值的 20% 以下，滤波效果大幅削弱，导致输出电压跌落。

改进：将所有 Y5V 电容更换为 X7R 或 X5R 材质，保证在 -40°C 至 +85°C 范围内容值变化在 ±15% 以内。

二、案例总结

案例根因教训
一去耦回路电感过大电容必须紧靠电源引脚
二DC 偏压致容值衰减参考 DC 偏压曲线选型
三ESL 限制高频去耦小封装电容推高谐振频率
四ESR 过低导致不稳LLC 谐振电容需考虑 ESR
五温度特性致容值衰减避免使用 Y5V，优先 X7R
