02 电容应用要点

02-电容应用要点

May 30, 20265 min read

  • 高速电路设计
  • 元器件

一、电容的主要参数

1.1 标称容值与精度

  • 常用精度：±5%（J）、±10%（K）、±20%（M）
  • 高速电路去耦精度要求不高（±20% 可接受）
  • 定时、滤波截止频率等场合需更高精度

1.2 额定电压

  • 降额使用：一般选择额定电压为实际工作电压的 1.5~2 倍
  • MLCC 在接近额定电压时容值衰减更严重

1.3 电容材质对比

材质温度特性DC偏压特性精度应用场景
C0G/NP0±30ppm/°C几乎无影响±5%谐振、定时、高频滤波
X7R±15%明显±10%通用去耦、滤波
X5R±15%明显±20%民用去耦
Y5V+22%/-82%严重±80%不推荐高速设计

选型建议：高频优先 C0G，通用去耦选 X7R/X5R，避免使用 Y5V。

二、高频特性：非理想模型

2.1 实际电容的等效模型

  • 实际电容 = C + ESR（等效串联电阻）+ ESL（等效串联电感）
  • 阻抗频率曲线呈 V 形：低频容性 → 谐振（阻抗最低）→ 高频感性

2.2 自谐振频率 SRF

  • 在 SRF 处阻抗最小，去耦效果最佳
  • 小容值 + 小封装 → 更高的 SRF
  • 典型值：0.1μF/0603 ≈ 40MHz；100pF/0402 ≈ 300MHz

2.3 ESL 的影响

  • 相同容值下，小封装 ESL 更小
  • 常见封装 ESL：0201 < 0402 < 0603 < 0805
  • 多颗小电容并联可有效降低 ESL

三、去耦电容设计

3.1 目标阻抗法

去耦网络的目标阻抗：

  • 去耦电容网络的总阻抗需在各频段都低于
  • 多颗不同容值的电容并联覆盖宽频段

3.2 经典去耦组合

频段电容封装作用
<1MHz10~100μF 电解/钽大低频储能
1~50MHz0.1~1μF MLCC0603/0805中频去耦
50~500MHz100~1000pF MLCC0402高频去耦
>500MHz10~100pF MLCC0201超高频去耦

3.3 PCB 布局铁律

  • 必遵：去耦电容与电源引脚之间回路面积最小化
  • 过孔放置在电容焊盘外侧（紧贴焊盘）
  • 电源和地平面为去耦提供低感抗返回路径
  • 多颗同值电容并联可降低 ESL

四、滤波应用

4.1 电源输入滤波器

  • 差模滤波：电容 + 电感（LC 滤波）
  • 共模滤波：共模扼流圈 + Y 电容

4.2 RC 滤波

  • 用于低速信号滤波、电源纹波抑制
  • 截止频率：
  • R 的压降需在可接受范围内

4.3 电容在高频滤波中的局限性

  • 超过 SRF 后电容呈感性，需配合磁珠使用
  • 实际工程师常犯错误：用大电容滤高频噪声（无效）

五、其他应用

应用关键要求推荐电容
定时/延时高精度、低漏电C0G、薄膜电容
ADC 采样保持低介电吸收C0G、聚丙烯
PLL 环路滤波低漏电、低温度系数C0G
AC 耦合高耐压、低失真MLCC（C0G）
储能/ bulk 电容大容值、低 ESR钽/铝电解

六、选型 checklist

  • 容值是否满足电路要求（考虑 DC 偏压衰减）？
  • 电压降额是否足够（1.5~2 倍）？
  • 材质是否满足工作温度范围（X7R 以上）？
  • 自谐振频率是否覆盖所需去耦频段？
  • ESL 是否在可接受范围？
  • ESR 是否合适（去耦需低 ESR，阻尼需适当 ESR）？
  • 封装是否满足 PCB 空间和布局要求？
  • 是否已考虑电容的寿命和可靠性（如 MLCC 裂纹风险）？
