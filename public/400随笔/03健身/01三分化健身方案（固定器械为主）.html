Day 1 推日（胸+肩+三头）

器械策略：自由重量为主 + 固定器械补充

动作类型组数×次数关键细节替代
杠铃卧推自由重量4×8-10肩胛骨下沉后缩贴凳，腰部自然弓起，下放至胸口史密斯机卧推 → 坐姿推胸机
哑铃上斜推胸自由重量3×10-12椅子30-45度，哑铃弧线推向锁骨，控制离心固定上斜推胸机 → 史密斯机上斜推
哑铃推举自由重量3×10-12背部贴紧，推至肘微屈不锁死史密斯机推举 → 器械推举机
哑铃侧平举自由重量3×12-15肘微屈，想象”倒水”，顶峰收缩1秒器械侧平举 → 绳索侧平举
绳索下压龙门架3×12-15大臂夹紧身体，只动小臂器械三头下压 → 哑铃颈后臂屈伸
平板支撑自重3×30-45秒核心收紧，臀不翘不塌-

动作详解

杠铃卧推

  • 躺平，眼睛在杠铃正下方
  • 肩胛骨下沉后缩，想象”塞进后裤兜”
  • 握距略宽于肩，手腕保持中立
  • 下放至乳头位置，触胸即推
  • 推起轨迹呈微弧线，非垂直上下

哑铃上斜推胸

  • 椅子调至30-45度（过高成肩推）
  • 哑铃起始位置在肩外侧，非胸口正上方
  • 推起时哑铃向中间靠拢，非直上直下
  • 顶端哑铃不相碰，保持张力

哑铃推举

  • 起始位：哑铃在肩外侧，肘略向前
  • 推起时想象”把哑铃扔向天花板”
  • 顶端肘关节微屈，不要锁死
  • 回放时控制速度，感受肩部拉伸

哑铃侧平举

  • 肘部微屈固定角度（约150度）
  • 想象”往两边倒水”，非”往上举”
  • 抬至肘与肩同高即可，过高伤肩
  • 顶峰收缩1秒，缓慢回放（3秒）

绳索下压

  • 大臂夹紧身体两侧，可夹毛巾防晃动
  • 身体略前倾，膝盖微屈
  • 只动小臂，大臂完全固定
  • 底端充分伸直，顶端充分拉伸

Day 2 拉日（背+肩后束+二头）⭐体态核心

器械策略：固定器械为主，体态改善关键日

动作类型组数×次数关键细节替代
高位下拉固定器械4×10-12宽握，先沉肩再内收，拉至锁骨，肘向后下方走龙门架直臂下压 → 哑铃单臂划船
坐姿划船固定器械4×10-12胸口贴挡板，拉至腹部，肩胛骨后缩挤压2秒龙门架坐姿划船 → 史密斯机俯身划船
反握高位下拉固定器械3×10-12窄握反握，刺激下背阔直臂下压
蝴蝶机反向飞鸟固定器械3×15-20面向器械坐，胸贴靠背，外展时打开胸膛龙门架反向飞鸟 → 哑铃俯身飞鸟
面拉 Face Pull龙门架3×15-20拉至面部两侧，外旋手臂，肩胛骨内收下沉弹力带面拉 → 哑铃外旋飞鸟
器械弯举固定器械3×10-12大臂固定软垫，专注二头收缩哑铃弯举 → 龙门架弯举 → 杠铃弯举
YTWL训练自重/小哑铃2组激活深层肌群矿泉水瓶代替哑铃

动作详解

高位下拉 ⭐改善圆肩王牌

  • 宽握，握距1.5倍肩宽
  • 起始位：肩胛骨上提（耸肩）
  • 动作分解：先沉肩 → 再内收 → 最后下拉
  • 拉至锁骨位置，想象”肘部向地面后方走”
  • 顶峰收缩2秒，感受背阔肌挤压
  • 回放时控制，感受拉伸

坐姿划船 ⭐改善驼背核心

  • 胸口完全贴紧挡板，不留缝隙
  • 起始位：手臂伸直，肩胛骨前伸
  • 拉动轨迹：向肚脐方向拉，非向胸口
  • 重点：拉到末端时肩胛骨用力后缩挤压
  • 保持2秒顶峰收缩，这是改善驼背的关键
  • 回放时肩胛骨缓慢前伸，感受中背拉伸

蝴蝶机反向飞鸟 ⭐圆肩克星

  • 面向器械而坐（反向使用）
  • 调整座椅使把手与肩同高或略低
  • 胸口完全贴紧靠背
  • 动作：外展手臂，想象”打开胸膛拥抱空气”
  • 顶峰时肩后束收缩，保持1秒
  • 回放时控制，感受后束拉伸

面拉 Face Pull ⭐必做体态动作

  • 绳索调至面部高度
  • 双手对握绳索，大拇指朝向自己
  • 拉至面部两侧时，外旋手臂（大拇指指向后脑勺）
  • 重点感受：肩胛骨向中间、向下方收紧
  • 这是改善圆肩最直接的动作，不可跳过

YTWL训练

  • 俯卧在斜板上，或站姿俯身
  • 依次做四个字母形状：
    • Y：手臂上举呈Y，激活下斜方肌
    • T：手臂平举呈T，激活中斜方肌
    • W：手臂弯曲呈W，激活肩外旋肌
    • L：大臂贴身体，小臂外旋呈L
  • 每个字母10-15次，轻重量慢控制

Day 3 腿日（下肢+核心）

器械策略：固定器械为主，安全高效

动作类型组数×次数关键细节替代
史密斯机深蹲半固定4×10-12双脚稍靠前，轨迹固定，蹲至大腿平行倒蹬机为主 → 哈克深蹲机 → 哑铃高脚杯深蹲
倒蹬机（腿举）固定器械3×12-15双脚放踏板中上部，膝盖对准脚尖，不锁死史密斯机深蹲加重 → 保加利亚分腿蹲
坐姿腿屈伸固定器械3×15挡板在脚踝上方，顶峰收缩股四头肌哑铃箭步蹲 → 靠墙静蹲
俯卧腿弯举固定器械3×12-15脚跟勾挡板，大腿贴紧，弯曲向臀部靠拢哑铃直腿硬拉 → 北欧腿弯举
髋外展机固定器械3×15膝盖外展顶峰收缩弹力带侧向行走 → 侧卧抬腿
器械卷腹固定器械3×15-20腹部发力，不拉头瑜伽垫卷腹 → 悬垂举腿

动作详解

史密斯机深蹲

  • 双脚站位比自由深蹲靠前5-10cm（轨迹适配）
  • 双脚与肩同宽，脚尖微外展
  • 下蹲时膝盖可自然超过脚尖（正常现象）
  • 蹲至大腿平行或略低，不要半程
  • 顶端膝盖微屈，不要完全锁死
  • 轨迹固定，可放心上重量

倒蹬机（腿举）

  • 双脚放踏板中上部（刺激更全面）
    • 高位：更多臀部
    • 低位：更多股四
    • 中上部：臀腿平衡
  • 膝盖对准脚尖方向，不要内扣
  • 下放至膝盖呈90度即可，过低伤腰
  • 蹬起时膝盖保持微屈，不锁死

坐姿腿屈伸

  • 调节挡板在脚踝上方，非脚背
  • 大腿完全贴紧座椅，臀部不抬起
  • 顶峰时充分伸直膝盖，收缩股四头肌
  • 回放时控制速度，感受拉伸
  • 可做部分次数（最后5次只做上半程）

弹力带推荐动作

弹力带面拉（无龙门架时）

  • 弹力带固定在头顶高度（门框/柱子）
  • 双手对握，拉向面部两侧
  • 拉至末端外旋手臂（大拇指向后）
  • 效果与绳索面拉几乎相同
  • 阻力可调：握距越短，阻力越大

弹力带高位下拉

  • 弹力带固定在高位（门框上方）
  • 跪姿或坐姿，双手下拉
  • 轨迹模拟高位下拉
  • 适合热身或正式组

圆肩驼背纠正逻辑

紧张肌肉（需拉伸）：

  • 胸大肌/胸小肌 → 门框拉伸
  • 上斜方肌 → 侧屈拉伸
  • 背阔肌（过度紧张时） → 高架悬挂

薄弱肌肉（需强化）：

  • 菱形肌 → 坐姿划船
  • 中下斜方肌 → YTWL训练
  • 肩外旋肌群 → 面拉外旋动作
  • 深层颈屈肌 → 下巴后缩

8周进阶计划

阶段周数重点策略
适应期1-2熟悉动作轻重量掌握轨迹，标记器械调节方法，建立训练习惯
积累期3-5建立基础拉日确保三个体态动作质量，每周尝试+1次或+1片重量
强化期6-8提升强度加入超级组（如划船+反向飞鸟连续），递减组（侧平举轻重递减）

每周检查清单

  • 完成4-5次训练
  • 拉日三个体态动作（高位下拉/划船/面拉）全部完成
  • 每日体态拉伸5分钟
  • 蛋白质摄入达标
  • 晨起有氧3次以上
  • 体重记录（每周固定时间称重）
  • 体态拍照对比（每2周正面/侧面各一张）

2个月预期效果

维度目标
体态圆肩明显改善，肩膀打开，锁骨更清晰，站立更挺拔
体脂下降3-5%，腹肌轮廓初现
力量主要动作重量提升20-30%
习惯训练成为自动行为，无需意志力启动
